feat(ui): Modernize Query Lab UI and remove unused sliders

## Major Changes:
1. Remove k_bm25 and k_faiss sliders (non-functional)
2. Add modern CSS styling with gradients and animations
3. Redesign header with purple gradient background
4. Update settings layout to 3-column design
5. Add custom metrics cards with color coding
6. Modernize all UI components (buttons, inputs, tabs)
